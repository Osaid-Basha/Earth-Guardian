# SafePath Demo Guide

## Quick Start

1. **Run the demo script:**
   ```bash
   demo.bat
   ```
   Or manually:
   ```bash
   npm install
   npm run dev
   ```

2. **Open your browser to:** `http://localhost:3000`

## Demo Features to Showcase

### 🏠 Home Screen
- **Interactive Map**: Shows color-coded risk zones (Yellow=Watch, Orange=Prepare, Red=Evacuate)
- **Risk Level Banner**: Displays current disaster risk level
- **Emergency Alert Card**: Appears when high risk is detected
- **Voice Alerts**: Toggle voice notifications for accessibility
- **Quick Actions**: Access to Safe Zones and SOS

### 🛡️ Safe Zones Screen
- **Shelter Database**: 5 mock shelters with real-time availability
- **Search Functionality**: Filter shelters by name or location
- **Contact Integration**: Direct calling and navigation buttons
- **Status Indicators**: Available, Limited, Full status for each shelter
- **Emergency Contacts**: Quick access to 911 and other emergency numbers

### 📚 Education Screen
- **Disaster Tips**: Comprehensive guides for 4 disaster types
- **Emergency Kit**: Essential items checklist
- **Expandable Sections**: Tap to expand detailed information
- **Emergency Numbers**: Quick access to important contacts

### 🌍 Accessibility Features
- **30+ Languages**: Switch between languages using the globe icon
- **RTL Support**: Full right-to-left support for Arabic
- **Voice Alerts**: Text-to-speech for emergency notifications
- **Large Touch Targets**: Easy-to-use buttons and controls
- **High Contrast**: Clear visual indicators

## Demo Scenarios

### Scenario 1: High Risk Alert
1. Navigate to Home screen
2. Notice the red "Evacuate" alert banner
3. Click "View Safe Zones" to see available shelters
4. Test the voice alert toggle

### Scenario 2: Safe Zone Search
1. Go to Safe Zones screen
2. Search for "Riyadh" to filter results
3. Click "Call" or "Directions" on any shelter
4. Notice the different status indicators

### Scenario 3: Educational Content
1. Navigate to Education screen
2. Tap on "Flood Safety" to expand tips
3. Review the emergency kit checklist
4. Check emergency contact numbers

### Scenario 4: Language Switching
1. Click the globe icon in the top-right
2. Switch to Arabic to see RTL layout
3. Notice how the interface adapts
4. Switch back to English
