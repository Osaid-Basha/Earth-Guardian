# SafePath - Disaster Management Mobile App

A comprehensive, modern mobile application for disaster management and emergency response, built with React and Tailwind CSS.

## 🌟 Features

### 🏠 **Home Screen**
- **Interactive Map**: Real-time map with Leaflet integration showing risk zones
- **Live Statistics**: Active alerts, safe zones, evacuated people, and risk levels
- **Emergency Alerts**: Real-time emergency notifications with SOS functionality
- **Quick Actions**: Easy access to safe zones and disaster tips

### 🛡️ **Safe Zones**
- **Comprehensive Database**: Detailed shelter information with real-time occupancy
- **Advanced Search**: Filter by availability, distance, and facilities
- **Interactive Features**: Call, get directions, and view detailed information
- **Real-time Updates**: Live occupancy status and last updated timestamps

### 📚 **Education & Tips**
- **Disaster Preparedness**: Comprehensive guides for floods, fires, earthquakes, and storms
- **Emergency Kit**: Essential items checklist and preparation tips
- **Emergency Numbers**: Quick access to all emergency services
- **Interactive Learning**: Expandable tips with visual indicators

### 📊 **Analytics Dashboard**
- **Disaster Statistics**: Real-time incident tracking and trends
- **Evacuation Metrics**: People evacuated, response times, and shelter usage
- **Risk Zone Analysis**: Detailed breakdown of affected areas
- **Performance Insights**: System efficiency and response metrics

### ⚙️ **Settings & Profile**
- **User Profile**: Personal information, achievements, and activity history
- **Customization**: Notifications, accessibility, and privacy settings
- **Device Status**: Battery, network, and location information
- **Emergency Contacts**: Manage personal emergency contacts

### 🚨 **Emergency System**
- **Real-time Chat**: Direct communication with emergency services
- **Emergency Types**: Flood, fire, earthquake, storm, medical, and other
- **Severity Levels**: Low, medium, high, and critical classifications
- **Quick Actions**: Call 911, share location, and emergency contacts

### 🌤️ **Weather Integration**
- **Current Conditions**: Temperature, humidity, wind, visibility, and pressure
- **5-Day Forecast**: Detailed weather predictions with alerts
- **Weather Alerts**: Severe weather warnings and safety tips
- **Interactive Charts**: Visual representation of weather data

### 📱 **Offline Mode**
- **Offline Features**: Access emergency contacts and safe zones without internet
- **Downloaded Maps**: Navigate using pre-downloaded map data
- **Sync Status**: Track data synchronization and offline capabilities
- **Connection Tips**: Guidance for better connectivity

## 🎨 **Design Features**

### **Modern UI/UX**
- **Glassmorphism**: Backdrop blur effects and translucent elements
- **Gradient Backgrounds**: Beautiful color transitions throughout the app
- **Smooth Animations**: Framer Motion animations for enhanced user experience
- **Responsive Design**: Optimized for mobile devices with touch-friendly interfaces

### **Accessibility**
- **Large Text Options**: Enhanced readability for all users
- **Voice Alerts**: Audio announcements for emergencies
- **High Contrast**: Clear visual indicators and status colors
- **Intuitive Navigation**: Easy-to-use interface with clear icons

### **Color Coding**
- **Risk Levels**: Red (High), Orange (Medium), Yellow (Low)
- **Status Indicators**: Green (Available), Yellow (Limited), Red (Full)
- **Emergency Types**: Color-coded icons and backgrounds
- **Weather Conditions**: Intuitive color schemes for different weather types

## 🛠️ **Technical Stack**

- **Frontend**: React 18 with modern hooks
- **Styling**: Tailwind CSS with custom components
- **Maps**: Leaflet with React-Leaflet integration
- **Animations**: Framer Motion for smooth transitions
- **Icons**: Lucide React for consistent iconography
- **Routing**: React Router for navigation
- **Build Tool**: Vite for fast development and building

## 🚀 **Quick Start**

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:3000` (or the port shown in terminal)

4. **Build for Production**:
   ```bash
   npm run build
   ```
